# 실시간 악보 · LIVE SCORE

건반으로 연주한 선율이 그 자리에서 악보가 되고, 가사를 붙이고, 편곡과 비교해 학생이 직접 고친 뒤 이유를 남기는 음악 창작 수업 플랫폼입니다.

- 플랫폼: https://edunity21.github.io/livescore/
- 사용 매뉴얼: https://edunity21.github.io/livescore-manual/
- OPEN SCORE Vol.01: https://edunity21.github.io/jnjmuse-mag/

## 여덟 단계

1. 연결하기 — MIDI 건반 자동 인식, 곡 제목·모둠 역할, 작곡 방식(건반/마우스)
2. 가사 쓰기 — 글자를 음절로 나누고 한 줄을 두 마디에 배치, 후렴 표시
3. 선율 연주 — 예비박 뒤 실시간 기록(피아노 롤), 화면 건반·마우스 입력, 🎤 흥얼거림 녹음(마이크 → 수노 Upload Audio용 MP3 + 음 높이를 찾아 가사가 붙은 악보, 내 선율로 쓰기)
4. 박 맞춤 — 4분·8분·16분음표 단위로 맞추고 음표 고치기
5. 가사 붙이기 — 음표 아래 가사, 끌어 옮기기, 두 글자 붙이기·늘이기, 줄별 확인(노랫말·음표가 없는 줄은 반주 마디)
6. AI 편곡 — 자동 편곡(연습·시연용, 규칙 기반) 또는 수노 스템 MIDI(받은 .zip 그대로 또는 .mid 여러 개)를 끌어다 놓으면 박을 맞춘 악보로 바로 바뀌고, 음표를 눌러 고치는 악보 편집(재생 빠르기 50~150%). 수노가 구간별로 쪼갠 트랙은 스템마다 합치고, 흔들리는 빠르기 지도는 박(틱) 기준으로 펴며, ÷2·×2와 반 박 단위 첫 박 옮기기로 박을 맞춘다
7. 비교·수정 — 바뀐 마디 표시, 듣고 고르기, 고친 이유 한 줄 기록
8. 악보 완성 — 고칠 수 있는 밴드 총보, MusicXML(뮤즈스코어)·MIDI·PDF·MP3(수노 Upload Audio용) 내보내기

## 더한 기능 (v7)

- **조성 8가지**(다·사·라·가·마·바·내림나·내림마장조)와 **곡 전체 조옮김**, **음역 점검**(편한 음역 도4~레5, 추천 조)
- **작곡 기법 도구** — 마디를 골라 반복·동형진행(2도 위/아래)·역행·전위로 다른 마디에 넣기(4단계)
- **코드 바꾸기** — 마디마다 코드를 고르면 반주가 다시 만들어지고, 화음음 비율로 어울림을 보여 줌(6단계)
- **장르 추가** — 댄스·힙합 / **파트별 음량 믹서**
- **노래방·발표 모드** — 전체 화면 가사, 지금 부를 글자 강조, 반주만(MR) 재생(8단계)
- **반주만 MP3(MR)**, **악보 그림(SVG)** 내보내기
- **자기평가·성찰**과 **과정 보고서**(노랫말·편곡 이유·마디별 수정 기록·자기평가·완성 악보를 한 장으로, PDF 저장)
- **작업 기록** — 지금 상태를 남기고 되돌리기, 새 곡·예시곡·파일 열기 전 자동 기록
- **교사용 모아보기**(teacher.html) — 모둠 프로젝트 파일 여러 개를 한 번에 열어 단계 진행·결정·이유·자기평가 확인, CSV로 받기

## 밴드 악보 (v8)

- **우리 편성(인원수)** — 악기마다 연주할 사람 수를 정하면, 사람이 실제로 연주할 수 있게만 파트를 계산합니다. 관악기·현악기는 한 사람이 한 음(같은 악기가 여럿이면 화음을 나눠 맡음), 키보드는 두 손(큰보표), 기타는 한 사람에 한 보표(1 리듬·코드, 2 리드·아르페지오), 베이스기타는 한 줄(한 옥타브 위로 적음), 드럼은 두 손과 큰북.
- **수노 MIDI는 재료로만** — 스템을 그대로 보표로 옮기지 않고, 화음·리듬·윤곽을 모아 우리 편성에 맞게 다시 계산합니다.
- **연주자용 총보** — 제목·부제·지은이·빠르기 말(예: Medium Pop ♩=92)·편성 줄, 전주(Intro, 후렴 첫 마디를 악기로), 리허설 표시(Intro/Verse/Chorus)와 겹세로줄, 셈여림(mp·mf), 주법(Dist.·P.M.·Clean), 맨 위 코드 기호, 악기 묶음(대괄호·중괄호)과 줄마다 마디 번호·악기 줄임 이름.
- **기보 규칙** — 박마다 빔으로 묶기(8분음표 넷은 반 마디로), 마디 가운데(3박)를 가리지 않게 붙임줄, 쉼표는 박을 보이게.
- **못갖춘마디(여린내기)** — 3단계에서 첫 마디를 고르면 짧은 첫 마디로 적고(0마디), 마지막 마디를 그만큼 짧게 맞춥니다. 가사 줄도 여린내기만큼 앞당겨 붙습니다.
- **스크롤 보기** — 피날레처럼 왼쪽에 보표 머리(음자리표·조표·악기 이름)를 고정합니다.
- **흥얼거림 녹음** — 작은 소리로 흥얼거려도 음을 찾도록 고쳤습니다.

## 악보 편집·인쇄·화성 (v9)

- **수노 MIDI 첫 박 자동 찾기** — 수노 MIDI는 마디가 박 몇 개 밀려 시작하기도 합니다. 넣을 때 크래시 심벌·큰북/작은북·긴 음·베이스가 모이는 자리를 찾아 마디 첫 박으로 맞추고(첫 박 앞에 음이 있으면 한 마디를 앞에 둠), 이미 만든 편곡도 악보 편집의 **◀ 한 박 · 반 박 · 한 박 ▶**으로 MIDI 파일 없이 옮길 수 있습니다.
- **타이프 인 스코어(가사 입력)** — 피날레처럼 음표를 누르고(또는 L) 글자를 친 뒤 띄어쓰기·Enter·Tab으로 다음 음표, Shift+Tab·←로 앞 음표, `-` 붙임표(영어 음절 hap-py), `_` 늘임, 빈 칸에서 ⌫ 앞 음표, Esc 끝. 한글 입력기 조합도 그대로 됩니다. 8단계에서 치면 2단계 노랫말과 5단계 글자 붙임이 함께 바뀝니다.
- **인쇄: 총보·파트보** — 페이지 보기의 **인쇄**(Ctrl+P)에서 총보 또는 파트보를 고릅니다. 파트보는 파트마다 새 쪽에서 시작하고 이어진 빈 마디는 여러 마디 쉼표로 묶으며, 클라리넷·트럼펫·색소폰은 연주자가 읽는 기보음(조표 포함)으로 인쇄합니다. 보표가 많은 총보는 한 단이 한 쪽에 들어가도록 크기를 맞춥니다. MusicXML도 이조 악기는 기보음 + `<transpose>`로 내보내 뮤즈스코어의 '실음 보기'가 맞습니다.
- **스크롤 보기 박자표 고정** — 왼쪽 보표 머리에 음자리표·조표와 함께 박자표도 고정합니다. 타악기 보표에는 조표를 적지 않습니다.
- **12개 장조 자유 이조** — 나·올림바·내림사·내림라·내림가장조를 더해 12개 장조 모두(딴이름한소리조 포함 13가지). 악보 편집과 총보 위의 **조옮김**(반음 ▼▲, 조 고르기)으로 곡 전체(내 선율·자동 편곡·수노 편곡)를 함께 옮깁니다. 올림바장조의 이끎음은 미♯, 내림사장조의 버금딸림음은 도♭으로 적습니다.
- **우리 편성 악기 17가지** — 관악기(플루트·리코더·클라리넷·알토 색소폰·트럼펫·트롬본), 현악기(바이올린·스트링·첼로), 기타·건반·베이스(기타·우쿨렐레·키보드·베이스기타), 타악기(실로폰·드럼·카혼·탬버린). 리코더·우쿨렐레는 반 전체(최대 30명)가 함께 할 수 있게 쉽게 — 리코더는 노래 선율을 쉽게, 우쿨렐레는 코드 기호와 리듬 빗금(스트로크). 악기마다 맡는 역할(훅·대선율·3도 화음 선율·혼 리프·아르페지오·뒷박)이 다르고 소리도 따로 냅니다.
- **코드 범위 2차 관계조까지** — 기본 6화음에 1차 관계조 화음·부속화음(II=V/V, III=V/vi, VI=V/ii, vii, v, ♭VII)과 2차 관계조·같은으뜸음조에서 빌려온 화음(VII=V/iii, iv, ♭VI, ♭III)을 더했습니다. 노래 음이 분명히 바랄 때만 쓰고, 코드 이름은 음 이름 자리대로(다장조 ♭VII = B♭) 적습니다.
- **한 마디에 코드 둘 이상** — 코드 바꾸기에서 **나누기·합치기**로 한 마디에 코드를 둘·넷까지, 자동 화성은 '코드 바뀜'(마디마다 1·2개, 박마다)으로 고릅니다. '이 설정으로 코드 다시 붙이기'는 자동 편곡과 수노 편곡 모두에 됩니다.

## 카메라로 만들기 (v10)

인터넷·AI 없이 브라우저 안에서만 영상을 다룹니다(영상은 어디로도 보내지 않음).

- **🖐 에어 건반**(3단계) — 화면 위쪽 8칸(그 조의 도~도)에 손을 넣으면 음이 울리고, ● 녹음으로 선율이 기록됩니다(움직임 감지).
- **✏️ 그림 선율**(3단계) — 종이에 그린 선율선을 비추거나 사진을 올리면, 줄마다 가사 글자 수만큼 음을 뽑아 선율을 만듭니다(높이 = 음 높이, 조의 음계).
- **👋 손 지휘 빠르기**(3단계) — 손을 지휘하듯 내렸다 올리면 박 간격으로 빠르기를 찾아 정합니다.
- **📸 모둠 사진**(1단계) — 과정 보고서·노래방 화면·교사용 모아보기에 들어갑니다.
- **🎬 뮤직비디오 녹화**(8단계) — 카메라 화면 위에 제목·가사 자막(지금 부를 글자 강조)을 얹고, 반주와 마이크 노래를 함께 녹화해 WebM으로 받습니다.

## 쓰는 환경

- 카메라 기능은 카메라 권한이 필요합니다(밝은 곳, 움직이지 않는 배경이 좋음).
- 노트북 크롬 또는 엣지(건반 연결은 Web MIDI가 되는 브라우저에서만). 건반이 없으면 마우스 입력.
- 모둠원 태블릿은 머리의 '태블릿으로 보기' QR로 지금 악보를 받아 보고 들을 수 있습니다(실시간 공동 편집은 아님).
- 마이크 녹음과 음 높이 찾기도 브라우저 안에서만 합니다. 서버나 AI API를 쓰지 않습니다. 작업 내용은 그 기기의 브라우저에만 저장되며, 메뉴에서 프로젝트 파일(.json)로 옮길 수 있습니다.
